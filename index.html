Auftrag 1 · Der Paketbaum (2 BE)

Gib bei einer Preorder-Traversierung nur Pakete mit Gewicht > 10 kg aus. Auch unter leichten Paketen können schwere Pakete liegen.

Klicke Knoten an, um sie für Auftrag 1 auszuwählen.

Ausgangscode · Vor der Fehlerdiagnose lesen

Ein Entwickler hat folgende Methode erstellt. Untersuche zunächst den Quellcode. In Auftrag 2 erklärst du den Fehler; in Auftrag 3 reparierst du die Methode im Editor.

public static void schwerePakete(BaumKnoten k) {
    if (k == null) {
        return;
    }

    if (k.getPaket().getGewicht() <= 10.0) {
        return;
    }

    System.out.println(k.getPaket().getNummer());

    schwerePakete(k.getLinks());
    schwerePakete(k.getRechts());
}

Auftrag 2 · Fehlerdiagnose 2 BE

Untersuche den oben abgedruckten Java-Ausgangscode. Erkläre, warum die Methode schwerePakete() beim dargestellten Paketbaum keine Paketnummer ausgibt, obwohl mehrere Pakete schwerer als 10 kg sind.

Auftrag 3 · Java-Code reparieren 4 BE

Ändere die Methode so, dass der Baum vollständig traversiert und ausschließlich schwere Pakete ausgegeben werden. Die Reihenfolge muss Preorder bleiben.

Hinweis anzeigen

Die Gewichtskontrolle darf nur die Ausgabe beeinflussen, nicht das Durchlaufen der Kinder. Der Nullfall bleibt als Abbruchbedingung erhalten.

Auftrag 4 · Rekursiver Ablauf 3 BE

Welche Pakete werden von einer korrekt reparierten Methode in Preorder ausgegeben? Gib die Paketnummern mit Leerzeichen ein.

Auftrag 5 · Laufzeit und Speicher 2 BE

Wähle die beiden korrekten Aussagen für eine vollständige rekursive Traversierung mit konstantem Aufwand je Knoten.

Auftrag 6 · Transfer: Optimieren? 2 BE

Unter welcher zusätzlichen Voraussetzung dürfte ein kompletter Teilbaum übersprungen werden, sobald sein Wurzelpaket höchstens 10 kg wiegt?

Abschluss der Code-Challenge

0 / 15 BE

Bearbeite die sechs Aufträge. Jeder Auftrag kann erneut geprüft werden; es zählt die jeweils erreichte Punktzahl.

Musterlösung

public static void schwerePakete(BaumKnoten k) {
    if (k == null) return;

    if (k.getPaket().getGewicht() > 10.0) {
        System.out.println(k.getPaket().getNummer());
    }

    schwerePakete(k.getLinks());
    schwerePakete(k.getRechts());
}
